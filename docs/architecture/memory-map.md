# DC-Chip 初版存储映射

- 版本：v0.1
- 状态：初版 CPU 实施基线
- 更新日期：2026-09-10
- ISA 规范：`docs/isa/isa.md` v0.1

## 1. 地址模型

初版只定义 CPU 可见的指令字地址空间。PC 为 8 位，地址单位是一个 16 位指令字，不是字节。

| 区域 | 字地址范围 | 容量 | 数据宽度 | 访问 | 副作用 |
| --- | --- | --- | --- | --- | --- |
| 指令空间 | `0x00`–`0xFF` | 256 个指令字 | 16 bit | CPU fetch-only | 无 |

PC 在普通指令提交后按模 256 加一，因而 `0xFF` 的下一顺序地址是 `0x00`。`JUMP` 直接用 8 位立即数选择该空间中的绝对字地址。

## 2. 指令接口行为

- `imem_addr` 是 8 位字地址；
- `imem_rdata` 返回完整 16 位指令；
- 初版接口只读、组合、零等待；
- 初版不定义字节使能、对齐异常、访问请求握手或总线错误；
- 由于 PC 覆盖完整 8 位范围，核心内部不存在超出 `0x00`–`0xFF` 的指令地址。

物理存储使用分布式 ROM、BRAM、PS 提供的数据还是其他实现均为 `TODO`。本规范不把字地址换算成尚未定义的物理字节地址。

## 3. 仿真镜像边界

HEX 镜像可以少于 256 个有效指令字。访问镜像已加载长度之外但仍位于架构指令空间内的地址时，仿真 wrapper 返回保留编码并记录越界，用于诊断测试程序错误。

该行为属于 behavioral simulation 环境，不是 ISA 异常、存储器副作用或未来硬件 ROM 的规范。最终一条目标指令提交后出现的未提交组合预取也不得被误报为已经执行的越界访问。
