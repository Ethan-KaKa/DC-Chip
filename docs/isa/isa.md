# DC-Chip 自定义指令集手册

- 版本：v0.1
- 状态：初版 CPU 的规范基线
- 更新日期：2026-09-10

## 1. 范围与兼容性

本文档是 DC-Chip 指令编码和体系结构语义的唯一规范源。初版 RTL、仿真器、测试程序和后续软件工具必须与本文档一致。

该指令集是课程项目使用的自定义 16 位 ISA，不是 RISC-V 子集，也不与 RISC-V 二进制兼容。NPC 和 NEMU 只能作为仿真组织及验证方法的参考，不能直接作为本 ISA 的执行语义。

本文档中的“必须”表示实现与测试需要遵守的规范行为；标为 `TODO` 的内容尚未定义，不得自行补全为架构行为。

## 2. 体系结构状态

| 项目 | 初版定义 |
| --- | --- |
| 指令宽度 | 16 bit，定长 |
| 数据宽度 | 16 bit |
| 通用寄存器 | `R0`、`R1`、`R2`、`R3`，均为 16 bit |
| PC 宽度 | 8 bit |
| PC 寻址单位 | 16 bit 指令字 |
| 复位 PC | `0x00` |
| 复位寄存器值 | `R0`–`R3` 全部为 `0x0000` |
| 字节序 | 初版没有数据访存；程序 HEX 文件按指令字表示，不定义字节序 |
| 状态标志 | 无 |
| 特权级 | 无 |

`R0` 是普通可写寄存器，不是常零寄存器。所有寄存器读均返回当前架构值。

## 3. 指令格式

所有指令使用同一个 16 位格式：

```text
 15          12 11       10 9          8 7                 0
+---------------+-----------+------------+-------------------+
| opcode[3:0]   | rd[1:0]   | rs[1:0]    | imm8[7:0]         |
+---------------+-----------+------------+-------------------+
```

寄存器编号如下：

| 编码 | 寄存器 |
| --- | --- |
| `00` | `R0` |
| `01` | `R1` |
| `10` | `R2` |
| `11` | `R3` |

为避免一条指令存在多个机器码，未使用字段必须编码为零：

| 指令形式 | `rd` | `rs` | `imm8` |
| --- | --- | --- | --- |
| 立即数运算 | 使用 | 必须为 `00` | 使用 |
| 寄存器运算 | 使用 | 使用 | 必须为 `0x00` |
| 绝对跳转 | 必须为 `00` | 必须为 `00` | 使用 |

已分配 opcode 中若未使用字段不为零，该指令属于非规范编码，按非法指令处理。

## 4. 通用执行规则

- 取指地址等于当前 `PC`，每个地址对应一个 16 位指令字。
- 除 `JUMP` 和非法指令外，提交后 `PC` 更新为 `(PC + 1) mod 256`。
- `JUMP` 的目标是绝对指令字地址，不是字节地址，也不是相对当前 PC 的偏移。
- 加减运算按无符号 16 位位模式执行，结果对 `2^16` 取模；ISA 不产生进位、溢出、零值或符号标志。
- `imm8` 在写入寄存器或参与运算前零扩展为 16 位。
- 单周期是初版微架构选择，不是软件可见的 ISA 要求。后续实现可以改变周期数，但不得改变提交顺序和结果。

## 5. Opcode 总表

| Opcode | 规范汇编格式 | 操作 |
| --- | --- | --- |
| `0x0` | `MOVI Rd, #imm8` | 立即数写寄存器 |
| `0x1` | `MOV Rd, Rs` | 寄存器复制 |
| `0x2` | `ADDI Rd, #imm8` | 寄存器加立即数 |
| `0x3` | `ADD Rd, Rs` | 寄存器加法 |
| `0x4` | `SUB Rd, Rs` | 寄存器减法 |
| `0x5` | `AND Rd, Rs` | 按位与 |
| `0x6` | `OR Rd, Rs` | 按位或 |
| `0x7` | `JUMP #addr8` | 绝对跳转 |
| `0x8` | Reserved | 非法指令 |
| `0x9` | Reserved | 非法指令 |
| `0xA` | Reserved | 非法指令 |
| `0xB` | Reserved | 非法指令 |
| `0xC` | Reserved | 非法指令 |
| `0xD` | Reserved | 非法指令 |
| `0xE` | Reserved | 非法指令 |
| `0xF` | Reserved | 非法指令 |

规范汇编助记符使用 `MOVI`/`MOV` 和 `ADDI`/`ADD` 区分立即数形式与寄存器形式。课件中的 `MOV Rd, #imm8` 和 `ADD Rd, #imm8` 仅作为来源记法，不作为本手册的规范拼写。

## 6. 指令语义

### 6.1 `MOVI`：立即数写寄存器

```text
encoding: 0000 rd 00 imm8
syntax:   MOVI Rd, #imm8
effect:   Rd <- zero_extend(imm8)
```

示例：`MOVI R1, #0x02` 编码为 `0x0402`，执行后 `R1 = 0x0002`。

### 6.2 `MOV`：寄存器复制

```text
encoding: 0001 rd rs 00000000
syntax:   MOV Rd, Rs
effect:   Rd <- Rs
```

示例：`MOV R2, R1` 编码为 `0x1900`。

### 6.3 `ADDI`：寄存器加立即数

```text
encoding: 0010 rd 00 imm8
syntax:   ADDI Rd, #imm8
effect:   Rd <- (Rd + zero_extend(imm8)) mod 2^16
```

示例：`ADDI R1, #0x08` 编码为 `0x2408`。

### 6.4 `ADD`：寄存器加法

```text
encoding: 0011 rd rs 00000000
syntax:   ADD Rd, Rs
effect:   Rd <- (Rd + Rs) mod 2^16
```

示例：`ADD R1, R2` 编码为 `0x3600`。

### 6.5 `SUB`：寄存器减法

```text
encoding: 0100 rd rs 00000000
syntax:   SUB Rd, Rs
effect:   Rd <- (Rd - Rs) mod 2^16
```

示例：`SUB R1, R2` 编码为 `0x4600`。

### 6.6 `AND`：按位与

```text
encoding: 0101 rd rs 00000000
syntax:   AND Rd, Rs
effect:   Rd <- Rd & Rs
```

示例：`AND R1, R2` 编码为 `0x5600`。

### 6.7 `OR`：按位或

```text
encoding: 0110 rd rs 00000000
syntax:   OR Rd, Rs
effect:   Rd <- Rd | Rs
```

示例：`OR R1, R2` 编码为 `0x6600`。

### 6.8 `JUMP`：绝对跳转

```text
encoding: 0111 00 00 addr8
syntax:   JUMP #addr8
effect:   PC <- addr8
```

示例：`JUMP #0x08` 编码为 `0x7008`。该指令不修改通用寄存器。

## 7. 非法指令行为

下列情况均为非法指令：

- opcode 位于 `0x8`–`0xF`；
- 已分配 opcode 的未使用字段不是零；
- 后续手册明确列出的其他非法编码。

初版核心检测到非法指令时必须：

1. 不写任何通用寄存器；
2. 保持 PC 不变；
3. 将 `illegal_inst` 置为 1，并保持到下一次复位。

初版不定义异常入口、异常原因寄存器或返回指令。仿真器应把 `illegal_inst` 视为失败并以非零状态结束。

## 9. 示例程序

下列程序覆盖全部 8 条基础指令：

```text
00: 0402    MOVI R1, #0x02
01: 1900    MOV  R2, R1
02: 2408    ADDI R1, #0x08
03: 3600    ADD  R1, R2
04: 4600    SUB  R1, R2
05: 5600    AND  R1, R2
06: 6600    OR   R1, R2
07: 7008    JUMP #0x08
```

从复位状态执行 8 条指令后，预期状态为：

```text
R0 = 0x0000
R1 = 0x0002
R2 = 0x0002
R3 = 0x0000
PC = 0x08
```

## 10. 扩展纪律

分配任何保留 opcode 前，必须先在本手册中记录编码、语法、操作数、伪代码、未使用字段和边界行为，再同步修改 RTL、独立参考模型、软件编码接口和定向测试。不能通过忽略比较或为同一语义增加未记录编码来掩盖错误。
