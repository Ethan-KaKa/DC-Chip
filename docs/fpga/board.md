## 3. 复位边界

CPU 核心接口使用同步高有效 `rst`，这是核心内部微架构约定，不代表板级复位极性。未来 FPGA wrapper 必须根据实际板级输入完成：

1. 必要的极性转换；
2. 异步输入同步；
3. 同步释放；
4. 向 CPU 核心提供同步高有效复位。

具体同步级数、时钟域和复位时序在板卡与输入时钟确认后定义，当前为 `TODO`。
